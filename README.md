# 9-10 General Math Practice

A static practice site for class 9-10 general math, in Bangla with an English switch.
Single file (`index.html`), no build step, no dependencies. Progress, stars and notes are saved in the visitor's browser.

## Publish

**GitHub Pages:** push to `main`, then Settings → Pages → Source: GitHub Actions
(the workflow in `.github/workflows/pages.yml` deploys automatically), or choose "Deploy from a branch" → `main` / root.

**Vercel:** Add New → Project → import this repo → Framework: Other → Deploy.

## Local preview

Open `index.html` in a browser.
